# 四级阅读 v0.3.2

## 手机使用

安装 v0.3.2 后进入「英语四级 → 真题」，点击「获取全部未下载试卷」或单套「获取本套30题」。下载后显示已下载题数；点击「开始本套阅读」可选整套30题或某题型10题。获取成功后文章和题目存放在应用私有目录，重启及断网后仍可作答；卸载会删除本地数据。使用原生 Android 控件，不嵌入来源网页。

APK 与 GitHub 只分发来源目录及解析程序。首次从 https://eol.nju.edu.cn/cet4/ 按套获取，校验已核对页面的 SHA-256 后解析、保存；页面变化时拒绝导入并提示更新目录。下载失败可重试，不计为已下载。真题正文、原卷和答案 PDF 的审核缓存不提交仓库。

## 内容范围

- 8套、240道独立小题，32篇不同文章；不是240篇或240套。
- 选词填空80题：每题带完整文章、15词词库，可提交该空的单词或词库字母。
- 段落匹配80题：保留全部段落，按该套实际段落字母选择。
- 仔细阅读80题：16篇文章，每篇5道四选一。
- 保留原有9条练习、8条真题摘选，另列摘选区域，新增240道不含这些摘选。
- 2023年12月第2套来源HTML缺P段但答案引用P，已排除。

## 来源与核验

范围：2023年12月第1/3套、2024年6月第1/2/3套、2024年12月第1/2/3套。公开页面中的答案与其链接的参考答案PDF均为同一来源，不能视作独立官方答案。

本机核验日期2026-11-15：

1. 每套题号26—55无缺失、无重复；词库15词，匹配答案对应段落存在。32篇文章及240道题按正文、题干检查无重复。
2. 240个答案逐个与来源答案PDF提取结果对照，无缺失或不一致。
3. 32篇文章按英文字母规范化后，与链接原卷PDF提取文字对比，全部字母内容按序覆盖；31篇连续一致，1篇因PDF段间插入内容以顺序匹配核对。此检查不等于人工校对标点、排版或考试机构认证。
4. 使用实际 Java 解析器逐套产生240条记录，与 Python 解析的正文、词库、段落、选项、答案、题号逐字段比对；缺段试卷会被拒绝。
5. 实际资料仓库代码在JVM中使用最小Android文件接口替身测试：8套下载解析、文件保存、创建新仓库实例后离线加载240题均通过；错误哈希及错误来源URL被拒绝，已有数据保留，损坏缓存不计数且重试可恢复。此项不代替Android设备测试。

当前仅给出来源参考答案、匹配对应原文与来源解析入口；没有把这些称作完整独立中文详解。APK编译、Lint、签名及内容清单另行检查。未完成手机真机验收，不能把本机检查说成用户手机已经更新。

## 开发验证

导入和审核脚本依赖 Python 包 beautifulsoup4、pypdf（可装在 tmp/python-deps）。运行 scripts/import_cet4_reading.py 建立本地审核缓存，再运行 scripts/audit_cet4_reading.py 比对答案和文章；scripts/test_reading_parser.py 执行实际Java解析器，与缓存逐字段对照。所有缓存均位于已忽略的 tmp/。发布前执行 npm run build:apk 和 gradle -p android-app lintDebug，并核对APK不含全文审核缓存。
