# 原书阅读与批注

用户要求是完整原书、重点标记和讲解。现有43章 JSON 是独立编写的辅助笔记，不是教材全文。不能把43个章节标题和摘要当成已经收录全书，也不能用安装包体积判断教材是否完整。

## 已实现

- 原生 Android PdfRenderer 显示完整 PDF 页面；不使用 WebView。
- 通过系统文件选择器导入有权使用的 PDF，验证可打开后原子替换本地副本；不改动用户的源文件。
- 按页阅读、缩放、跳页、记录进度，并校准“正文第1页”对应的 PDF 页数。章节目录和页码按中文第一版，其他版本需要核对。
- 拖动框选重点，以相对页面坐标保存，缩放后位置一致；本地保存、编辑、删除批注。
- 按正文页码显示已有独立章节辅助讲解。当前讲解不是逐页原文分析，不会自动识别 PDF 文字。
- 原书文件、阅读位置和重点批注仅保存在设备应用私有目录；换书按 SHA-256 区分笔记。卸载应用会删除本地文件。
